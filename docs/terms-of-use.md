# Termos de uso — GameStore Studio

Esta é a versão para publicar junto da ficha da loja. O mesmo texto aparece no aplicativo.

## A loja

O GameStore Studio é a vitrine do proprietário para vender e distribuir os próprios jogos. O catálogo mostra somente jogos que esse administrador publicou.

## Conta e compra

O usuário é responsável pela senha. O preço cobrado é o preço gravado no servidor no momento do pedido. A compra entra na biblioteca quando o pagamento é confirmado pelo backend.

## Downloads

Os arquivos ficam em armazenamento privado. O link é temporário e só é emitido para quem comprou o jogo. Uma nova versão publicada fica disponível para quem já comprou.

## Licença

A compra concede licença de uso pessoal do jogo. Ela não transfere a propriedade intelectual.

## Conduta

É proibido acessar o painel, os arquivos privados ou o fluxo de pagamento sem autorização.

## Encerramento

O usuário pode excluir a própria conta. O proprietário pode despublicar um jogo. Registros de venda podem ser mantidos sem os dados pessoais da conta excluída.
